# Overview

Inspera is an assessment platform design system. Its character is **calm, systematic, and information-first** - engineering-grade UI, not marketing flourish.

- **Ground:** light canvas (`--gray-100` / white surfaces), hairline borders (`--gray-200` / `--gray-300`).
- **Accent:** deep navy `--primary` (`#004080`) is the single interactive accent. Use it for primary actions, links, active states, and focus. Secondary brand purple `--secondary` (`#322060`) is used sparingly.
- **Semantics:** `--info`, `--success`, `--warning`, `--error` carry meaning - use them only for their meaning.
- **Corners:** small-to-medium radii (`--radius-sm` for controls, `--radius-md` for inputs/alerts, `--radius-lg` for cards/dialogs). Pills only for toggles, badges, radios, avatars.
- **Elevation:** flat by default; use `--shadow-200` for cards, `--shadow-500` for dialogs. Prefer borders over shadows for separation.
- **Type:** Inter for all UI; Noto Sans Mono for code/values; Noto Serif for long-form; Material Symbols Outlined for icons.
- **Density:** compact and scannable. Consistent padding from the spacing scale. Avoid decorative whitespace.
