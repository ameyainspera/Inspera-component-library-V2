# Inspera Design System - Kit Guidelines

**MUST READ before writing any code.** This kit is the single source of truth for Inspera UI in Figma Make. Use only the components, tokens, and icons defined here - do not invent variants, rename props, or hardcode off-palette colors.

Read these in order:

1. **setup.md** - install and wiring (import `styles.css`, register fonts). Execute first.
2. **overview.md** - how the system should look and feel.
3. **tokens.md** - color, spacing, radius, shadow, typography tokens. Know the token names before generating UI.
4. **components.md** - the 15-component catalog with exact prop names, variants, and accessibility rules. Read the entry for each component before using it.
5. **icons.md** - icon set and usage rules.

Everything in `tokens.md`, `components.md`, and `styles.css` is generated from the Inspera source of truth - never edit those by hand.
