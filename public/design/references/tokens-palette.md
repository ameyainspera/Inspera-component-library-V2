# Colour palette tokens

> Reference file for `DESIGN.md` (Inspera Design System). Read it when you need a raw palette shade that is not one of the role tokens in DESIGN.md (role tokens come first). `DESIGN.md` wins if the two disagree.

Each family runs from 100 (lightest) to 900 (darkest). 100–300 are surface tints. Lightest shade that is safe for text on white or the gray-100 canvas: gray, blue, green and pink **700**; yellow and orange **800**; red and purple **600**. CSS variable = token name, for example `var(--blue-700)`.
